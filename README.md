# Three Human Desires｜三欲动力学模型

**当前版本：5.4**

三欲动力学模型的目的，是通过区分三欲，以动力学的角度理解生活中的欲望、感受和行为怎样形成与变化，并帮助人更清晰地生活。

## 简介

三欲动力学模型把人的欲望主要区分为三类：

- **身体欲望**，简称**性欲**
- **掌控欲望**，简称**情欲**
- **他利欲望**，简称**爱欲**

这里的“性欲、情欲、爱欲”是项目内部沿用的简称，具体含义以本项目中的定义为准。

模型不根据一个人做了什么，就直接判断他有什么欲望。相同的行为可以来自不同欲望，同一个行为也可以同时受到多种欲望推动。

在此基础上，模型从动力变化的角度继续分析：人的当前状态怎样形成欲望，欲望怎样参与行为，现实变化怎样形成感受，感受又怎样更新之后的状态和欲望。

其中，模型进一步区分了掌控欲望的增殖、衰退、强化、代偿，以及反刍、泛化、转化等不同过程，并尝试用这些结构重新理解关系、修行和日常生活中的一些常见现象。

这个模型不是人格分类，也不把三种欲望划分为不同的道德等级。它目前主要是一套基于常识观察建立的定性分析框架。

本仓库初始公开版本对应**三欲动力学模型 5.4 草稿版**。

目前为5.4版本（github初始版本），后续将添加英文翻译版本。
