# 相关理论

三欲动力学模型基于常识观察独立形成。

这里列出的其他理论，仅用于说明某些术语、结构或表述上的相似与不同，不作为三欲动力学模型的理论来源。

本文也不比较各理论的：

- 成熟程度；
- 证据规模；
- 历史地位；
- 应用范围；
- 尚未解决的问题。

本文只讨论一个更有限的问题：

> **其他理论中哪些结构容易让人联想到三欲动力学模型，以及这些相似究竟到哪里为止。**

三欲动力学模型当前以：

> **状态怎样形成欲望，状态与欲望怎样共同参与行为，主体怎样通过真实世界中的实际变化形成实际感受结构并持续更新状态**

作为基础过程。

在此基础上，一个已经充分拆分的具体欲望按照基本动力学特征分类：

\[
\boxed{
\text{性欲：满足后的条件依赖性再生}
}
\]

\[
\boxed{
\text{情欲：增殖}
}
\]

\[
\boxed{
\text{爱欲：与相关他利态绑定并同步}
}
\]

因此，后文所有外部理论都只与这些已经建立的结构进行对照。

---

# 一、比较范围与原则

## 1. 为什么比较相关理论

### 文字解释

三欲动力学模型使用了一些非常常见的词，例如：

- 状态；
- 动力；
- 欲望；
- 控制；
- 满足；
- 反馈；
- 强化；
- 调节；
- 关系。

这些词在心理学、生理学、控制理论、人工智能和神经科学中也经常出现。

问题在于：

> **相同的词，在不同理论中不一定指同一个概念。**

例如：

三欲模型中的“情欲”在人类中主要表现为掌控欲望。

但控制理论中的“control”首先描述的是一种系统结构。

三欲模型中的“强化”是一个定义非常狭窄的情欲动力过程。

而强化学习中的“reinforcement”则处在完全不同的理论框架中。

如果只因为词语相似就直接互换，很容易把三欲模型重新解释成另一套理论。

因此，列出相关理论的主要目的不是证明：

> 三欲模型和其他理论“其实是一样的”。

而是为了明确：

> **哪些局部结构可以类比，哪些概念必须保持分离。**

### 符号与结构对照

本文采用两个基本原则：

\[
\boxed{
\text{术语相似}
\not\Rightarrow
\text{概念相同}
}
\]

以及：

\[
\boxed{
\text{局部结构相似}
\not\Rightarrow
\text{理论等价}
}
\]

同样：

\[
\boxed{
\text{可以进行比较}
\neq
\text{存在理论来源关系}
}
\]

---

## 2. 比较的边界与方法

### 文字解释

本文不尝试完整介绍任何一个外部理论。

每一部分只选择：

> **与三欲动力学模型存在直接概念重叠或者容易造成误读的部分。**

比较主要围绕五个问题进行：

第一：

> **双方正在分析什么对象？**

例如是在分析生理变量、具体欲望、行为、奖励、关系，还是知觉控制。

第二：

> **状态怎样参与后续过程？**

第三：

> **动力从哪里产生？**

第四：

> **反馈、满足、奖励或者结果怎样影响后续变化？**

第五：

> **双方究竟按照什么标准分类？**

这五个问题尤其重要。

因为两个理论即使拥有非常相似的箭头结构，只要：

> 分类对象不同，

或者：

> 分类依据不同，

就不能直接视为同一理论。

### 符号与结构对照

三欲动力学模型的基础比较坐标为：

\[
\Sigma_t\rightarrow\mathcal D_t
\]

\[
(\Sigma_t,\mathcal D_t)\rightarrow A_t
\]

\[
A_t+\text{其他现实过程}
\rightarrow
\text{实际变化}
\]

\[
(\Sigma_t,\text{实际变化})
\rightarrow
\text{实际感受结构}
\]

\[
(\Sigma_t,\text{期间其他状态演化},\text{实际感受结构})
\rightarrow
\Sigma_{t+1}
\]

以及：

\[
\boxed{
d_i
\xrightarrow{\text{基本动力学特征}}
\{d_s,d_c,d_l\}
}
\]

外部理论如果出现类似箭头，只表示：

> 可以在该局部结构上进行比较。

# 二、稳态与异稳态

稳态与异稳态首先涉及生理调节。

稳态通常用于描述生理系统怎样维持重要内部变量在可调节范围内；异稳态的常见表述则强调“通过变化获得稳定”，并把预期、学习和对未来需求的提前调节纳入分析。异稳态的具体边界在相关文献中并非完全统一，因此本文只使用这一最小比较意义。

## 3. 与身体调节和性欲的相似

### 文字解释

三欲模型中，人类性欲主要表现为与身体：

- 维持；
- 恢复；
- 调节；
- 身体性满足；

相关的动力。

例如：

- 进食；
- 补水；
- 睡眠；
- 休息；
- 治疗；
- 体温调节。

这些现象与稳态调节存在明显的结构相似。

例如身体缺水以后：

> 身体条件发生变化  
> → 形成相关动力  
> → 行为参与现实改变  
> → 身体重新获得水分  
> → 当前补水欲望受到消减。

稳态理论同样关注：

> 某些重要生理变量发生偏离以后，系统怎样通过调节使它们回到适合维持生命活动的范围。

因此，稳态能够与三欲模型中的：

> **身体条件、状态调节和身体相关欲望**

进行局部比较。

但二者分析对象并不相同。

稳态首先描述：

> **生理调节结构。**

三欲模型中的性欲则描述：

> **当前推动相关变化的具体动力。**

所以：

> 身体正在发生稳态调节

并不意味着：

> 稳态本身就是性欲。

一些生理调节甚至可以在没有当前可识别具体欲望的情况下自动发生。

### 符号与结构对照

三欲模型中的性欲：

\[
\Sigma_t\rightarrow d_s
\]

相应满足后：

\[
d_s
\rightarrow
\text{满足}
\rightarrow
\text{当前消减}
\]

相关条件再次出现：

\[
\text{相关条件再次出现}
\rightarrow
d_s'
\]

稳态可以粗略示意为：

\[
\text{受调节变量发生偏离}
\rightarrow
\text{调节过程}
\rightarrow
\text{变量恢复或维持}
\]

两者存在局部相似，但：

\[
\boxed{
\text{稳态调节}
\neq
d_s
}
\]

因为：

\[
\boxed{
\text{生理调节过程}
\neq
\text{当前具体欲望}
}
\]

## 4. 稳态、异稳态与性欲的区别

### 文字解释

如果只使用最简单的稳态图景，容易把性欲理解成：

> 身体先发生明显偏离，然后主体才产生欲望去恢复它。

三欲模型并不要求这种顺序。

主体状态中可以已经包含：

- 记忆；
- 预期；
- 条件化处理认知；
- 对未来变化的判断。

这些状态都可以参与具体欲望形成。

异稳态相关讨论特别强调：

> 调节可以具有提前性，过去经验和对未来需要的预测可以参与当前调节，而不是必须等到受调节变量已经严重偏离以后才反应。

这一点与三欲模型允许：

> 预期和已有状态参与性欲形成

具有可比较之处。

例如，一个人知道很快将进入长时间无法饮水的环境，于是提前形成补水相关欲望，并不要求他当时已经出现明显口渴。

但即使如此：

> 异稳态也不是性欲定义。

三欲模型仍然按照：

> **满足后的条件依赖性再生**

对性欲分类。

因此，稳态和异稳态主要帮助理解：

> 身体条件和调节可能怎样进入状态。

它们并不替代三欲模型对于具体欲望的分类。

### 符号与结构对照

三欲模型中：

\[
\Sigma
\]

可以包含：

\[
\text{身体条件} +
\text{预期} +
\text{条件化处理认知}
+\cdots
\]

因此：

\[
\Sigma\rightarrow d_s
\]

并不要求：

\[
\text{明显痛苦}
\]

已经先出现。

所以：

\[
\boxed{
\text{性欲形成}
\not\Rightarrow
\text{主体必须已经出现明显身体失衡感受}
}
\]

同时：

\[
\boxed{
\text{稳态 / 异稳态}
\neq
\text{性欲}
}
\]

三欲模型真正的性欲分类标准仍然是：

\[
\boxed{
\text{满足后的条件依赖性再生}
}
\]

# 三、控制论与知觉控制理论

知觉控制理论（Perceptual Control Theory，PCT）把控制理解为：主体通过行为抵消环境扰动，使某个被控制的知觉维持在内部参考值附近。其基础结构通常包括参考值、当前知觉、二者差异形成的误差，以及通过环境反馈改变知觉的输出过程。

## 5. 参照、知觉与现实调节

### 文字解释

知觉控制理论与三欲模型中的人类情欲存在非常明显的表面结构相似。

三欲模型把人类情欲的主要表现描述为：

> **推动感受到的自己、他人或现实更加符合自身预设的动力。**

知觉控制理论则描述：

> 系统内部存在参考值，当前知觉与参考值之间形成误差，行为通过作用于环境，使被控制的知觉重新接近参考值。

因此双方都可以出现：

> 内部参考  
> → 当前感受或知觉  
> → 两者之间存在差异  
> → 行为作用于现实  
> → 后续知觉发生变化。

这种相似是所有相关理论中最值得直接辨析的一种。

例如，一个人希望房间保持安静。

知觉控制理论可以分析：

> 当前噪音水平偏离参考水平，于是主体行动，使感受到的噪音重新接近希望的状态。

三欲模型也可以分析：

> 主体已有相关预设，在当前状态下形成具体掌控欲望，推动现实被感受到更加符合这一预设。

但是，两个模型的分类位置不同。

知觉控制理论首先解释：

> **控制系统怎样运行。**

三欲模型则进一步问：

> **当前推动这种变化的具体欲望属于哪一种动力类型。**

### 符号与结构对照

知觉控制理论常见的基础表达是：

\[
e=r-p
\]

其中：

- \(r\)：内部参考值；
- \(p\)：当前知觉；
- \(e\)：两者之间的误差。

误差进一步参与形成输出，并通过环境反馈影响被控制的知觉。

三欲模型中，相关结构可以表示为：

\[
d_c^O
\]

其中：

\[
O
\]

表示当前掌控内容。

具体情欲推动：

\[
O
\]

被感受到更加符合主体已有预设。

因此两者可以局部类比为：

\[
\text{参考值}
\sim
\text{相关预设}
\]

\[
\text{当前知觉}
\sim
\text{主体实际获得的相关内容}
\]

但：

\[
\boxed{
r-p
\neq
d_c^O
}
\]

---

## 6. 控制结构与情欲的区别

### 文字解释

最重要的区别是：

> **知觉控制理论中的“控制”不是三欲模型中的“情欲”。**

控制理论意义上的控制是一种系统组织方式。

只要一个系统通过行为和反馈，使某个被控制变量接近参考状态，就可以讨论控制结构。

但在三欲模型中：

> **情欲是一种具体欲望类型。**

而且情欲真正的分类依据不是：

> 主体是否在调整现实。

而是：

> **这个具体欲望是否具有增殖特征。**

例如，一个人极度口渴，形成补水欲望。

他可以：

- 找杯子；
- 打开水龙头；
- 调节水温；
- 喝水；

整个过程中都在通过行为改变现实，使身体重新获得适合的状态。

这个过程完全可以呈现负反馈调节特征。

但如果具体欲望的基本动力结构是：

> 满足后当前消减，之后主要在相关身体条件再次出现时重新形成，

它仍然属于性欲，而不是因为存在“控制”结构就变成情欲。

反过来，一个具体情欲也不要求必须表现为强迫别人或者明显控制行为。

主体甚至可以完全没有形成相应外部行为。

因此：

> “存在控制系统”

和：

> “存在情欲”

是两个不同层级的问题。

### 符号与结构对照

知觉控制结构：

\[
e=r-p
\]

不能推出：

\[
d_c
\]

即：

\[
\boxed{
\text{存在参考值—误差—反馈控制}
\not\Rightarrow
\text{存在情欲}
}
\]

三欲模型对于已经充分拆分的具体欲望要求：

\[
\boxed{
\text{能够确认增殖}
\Rightarrow
\text{情欲分类}
}
\]

因此：

\[
\boxed{
\text{控制论中的 control}
\neq
\text{三欲模型中的情欲}
}
\]

# 四、强化学习

强化学习（Reinforcement Learning，RL）的经典形式把智能体与环境描述为连续交互：智能体获得状态表征、选择行动，环境随后产生奖励并进入新的状态；智能体的学习目标通常与长期累计奖励有关。

## 7. 状态、行动、奖励与反馈

### 文字解释

强化学习和三欲动力学模型都存在明显的：

> 状态 → 行动 → 环境结果 → 后续状态

结构。

这使二者在形式图上看起来很相似。

经典强化学习中的智能体在某一状态下选择行动。

行动以后，环境给出：

- 新状态；
- 数值奖励。

这些连续交互共同构成学习过程。

三欲动力学模型也有：

> 当前状态  
> → 欲望  
> → 行为  
> → 实际变化  
> → 实际感受结构  
> → 后续状态。

但其中增加了几个在强化学习最小形式中并不对应同一层级的概念。

首先，三欲模型明确区分：

> **状态**

与：

> **欲望。**

其次，三欲模型明确区分：

> **真实世界中的实际变化**

与：

> **主体获得的实际感受结构。**

再者：

> 三欲模型中的反馈

被定义为主体行为实际造成或参与造成的现实结果。

它不等于实际感受结构。

因此，强化学习中的 reward 不能直接被翻译成三欲模型中的：

- 反馈；
- 满足；
- 实际感受结构；

中的任何一个。

它们分别处在不同理论结构中。

### 符号与结构对照

强化学习中的经典交互可以表示为：

\[
S_t
\rightarrow
A_t
\rightarrow
R_{t+1},S_{t+1}
\]

其中：

- \(S_t\)：智能体获得的状态表征；
- \(A_t\)：行动；
- \(R_{t+1}\)：数值奖励。

三欲动力学模型则写为：

\[
\Sigma_t\rightarrow\mathcal D_t
\]

\[
(\Sigma_t,\mathcal D_t)\rightarrow A_t
\]

\[
A_t+\text{其他现实过程}
\rightarrow
\text{实际变化}
\]

\[
(\Sigma_t,\text{实际变化})
\rightarrow
\text{实际感受结构}
\]

\[
(\Sigma_t,\text{期间其他状态演化},\text{实际感受结构})
\rightarrow
\Sigma_{t+1}
\]

因此：

\[
\boxed{
S_{\text{RL}}
\neq
\Sigma
}
\]

不能默认完全同义。

同样：

\[
\boxed{
R_{\text{RL}}
\neq
\text{反馈}
}
\]

\[
\boxed{
R_{\text{RL}}
\neq
\text{掌控满足}
}
\]

\[
\boxed{
R_{\text{RL}}
\neq
\text{实际感受结构}
}
\]

---

## 8. Reward、强化与增殖的区别

### 文字解释

“强化学习”这个名称尤其容易与三欲模型中的：

> **强化**

混淆。

但是两者不是同一个概念。

三欲模型中的强化有一个很窄的定义：

> **掌控满足自身的增殖作用以外，其他实际感受结构及相关状态演化，使同一具体情欲更容易形成或者形成得更强。**

同时，如果：

> 掌控满足本身

造成以后相关情欲形成倾向增强，则不称为强化，而称为：

> **增殖。**

强化学习中的 reinforcement / reward 则处在：

> 智能体通过奖励信号学习行动选择和长期回报

这一形式系统中。经典强化学习把奖励处理为特殊的数值信号，并研究行动怎样影响当前和未来奖励。

因此不能因为：

> 一个 reward 改变了以后行为，

就直接说：

> 这就是三欲模型的“强化”。

也不能因为：

> 奖励导致某种行动后来更常出现，

就直接把它叫作情欲“增殖”。

三欲模型中的增殖所讨论的是：

> **掌控满足本身对之后相关具体情欲形成的作用。**

它首先是一个欲望动力概念，而不是行为学习频率概念。

### 符号与结构对照

三欲模型：

\[
\boxed{
\text{掌控满足自身造成的后续增强} =
\text{增殖}
}
\]

而：

\[
\boxed{
\text{其他实际感受结构和状态演化造成同一具体情欲增强} =
\text{强化}
}
\]

强化学习中的：

\[
R_t
\]

则是其形式模型中的奖励信号。

因此：

\[
\boxed{
R_t
\neq
\text{三欲模型中的强化}
}
\]

同时：

\[
\boxed{
\text{reinforcement learning}
\neq
\text{三欲模型中的增殖机制}
}
\]

# 五、激励显著性： “wanting” 与 “liking”

激励显著性相关研究把 reward 中的不同心理成分进行区分，其中常见的三个成分是 “wanting”、 “liking” 和 learning。“liking”主要指奖励的享乐影响；激励显著性意义上的“wanting”则是一种特定的奖励动机过程，而且这种“wanting”可以与“liking”发生分离。

## 9. “wanting”与“liking”

### 文字解释

这一理论与三欲模型存在一个非常值得比较的基本结构：

> **动力不等于满足。**

在日常语言中，“想要”和“喜欢”经常混在一起。

激励显著性研究明确区分：

> “wanting”

和：

> “liking”。

其中，“liking”主要指奖励产生的享乐影响；“wanting”则指激励显著性这一特定奖励动机过程。相关研究强调，两者虽然通常一起出现，但在一些条件下可以发生分离。

三欲动力学模型同样区分：

- 欲望；
- 实际感受结构；
- 满足。

因此双方都反对一种过于简单的理解：

> “越喜欢，就一定越想要。”

或者：

> “想要本身就是满足。”

但是，两者的“wanting / 欲望”不能直接互换。

三欲模型中的欲望定义更加一般：

> **当前推动相关变化的动力。**

它可以属于：

- 性欲；
- 情欲；
- 爱欲。

激励显著性中的 “wanting” 则是奖励神经科学中的一个特定概念，而且相关作者明确指出，它并不等于日常语言中所有有意识的“想要”。

所以：

> 两个理论都区分动力和享乐，

并不意味着它们对“欲望”使用了同一个定义。

### 符号与结构对照

三欲动力学模型：

\[
d_i
\neq
\text{满足}
\]

激励显著性理论中：

\[
\text{“wanting”}
\neq
\text{“liking”}
\]

因此存在局部结构相似：

\[
\text{动力}
\neq
\text{享乐结果}
\]

但：

\[
\boxed{
d_i
\neq
\text{incentive salience “wanting”}
}
\]

也不能建立：

\[
\text{“liking”}
=
\text{三欲模型中的满足}
\]

二者只是存在可比较关系。

---

## 10. 激励敏化与情欲增殖的区别

### 文字解释

激励敏化理论特别容易让人联想到三欲模型中的：

> **情欲增殖。**

相关理论提出，在成瘾等特定过程中，与奖励有关的激励显著性“wanting”可以被长期敏化，从而使与奖励及其线索相关的动机反应异常增强，而且这种增强不要求“liking”同步增强。

这与三欲模型中的情欲增殖存在一种表面相似：

> 某种动力在后续变得更容易形成或者更强。

但二者真正的定义依据不同。

激励敏化主要讨论：

> 特定奖励及其线索相关的“wanting”怎样因为神经敏化等过程变得异常强。

三欲模型的情欲增殖则要求：

> **此前掌控满足本身，对之后相关情欲的形成倾向或者形成后强度产生增强方向。**

因此：

> “后来的 wanting 变强”

不能直接翻译成：

> “发生了情欲增殖”。

还必须检查：

- 当前是不是三欲模型中的具体情欲；
- 此前是否形成了相应掌控满足；
- 后续增强是否实际来自这一掌控满足；
- 是否存在其他强化来源。

三欲模型目前也没有把情欲增殖定义为：

> 某一种具体多巴胺机制。

所以即使未来发现二者存在经验联系，也仍然需要独立建立映射。

### 符号与结构对照

情欲增殖：

\[
\text{掌控满足}
\rightarrow
\begin{cases}
\text{当前相关情欲受到消减}\\
\text{后续相关情欲增强方向}
\end{cases}
\]

激励敏化可以结构性概括为：

\[
\text{reward / cue related “wanting”}
\rightarrow
\text{sensitization}
\]

但：

\[
\boxed{
\text{激励敏化}
\neq
\text{情欲增殖}
}
\]

尤其不能仅由：

\[
\text{后续动机增强}
\]

推出：

\[
\text{情欲增殖}
\]

---

# 六、驱力降低理论

Clark Hull 的驱力降低理论把生理或心理需要造成的 drive state 纳入动机和学习解释，并把 drive 的降低与反应的强化联系起来。APA 对其最简概括是：动机行为以降低 drive state 为目标，而成功降低 drive 的反应倾向于被强化。

## 11. 驱力降低与性欲

### 文字解释

驱力降低理论与三欲模型中的人类性欲存在非常直接的表面相似。

例如：

> 饥饿形成动力  
> → 寻找食物  
> → 进食  
> → 饥饿降低。

这与三欲模型中：

> 身体条件变化  
> → 形成具体性欲  
> → 行为参与满足  
> → 当前具体欲望消减

非常相似。

Hull 式驱力理论尤其把：

> 生理需要、drive、行为和 drive reduction

联系起来，并认为 drive reduction 可以参与学习中的强化。

因此，驱力降低理论是三欲模型中：

> **人类性欲**

最容易被联想到的经典动机理论之一。

但是，三欲模型中的性欲并不等于 drive。

首先，性欲的完整分类结构不仅包括：

> 满足后的当前消减，

还包括：

> **相关条件再次出现以后，相似具体欲望重新形成。**

其次，三欲模型没有把：

> 所有个人动力

都解释成身体 drive 的降低。

情欲和爱欲具有完全不同的基本动力学分类标准。

再次，三欲模型中的：

> 性欲满足

也没有被定义为：

> 对行为进行学习强化的统一机制。

所以二者只能在：

> 部分身体动力的形成和满足后下降

这一局部结构上类比。

### 符号与结构对照

驱力降低可以粗略概括为：

\[
\text{need}
\rightarrow
\text{drive}
\rightarrow
\text{behavior}
\rightarrow
\text{drive reduction}
\]

三欲模型：

\[
\text{相关身体条件}
\rightarrow
d_s
\]

\[
d_s
\rightarrow
\text{满足}
\rightarrow
\text{当前消减}
\]

\[
\text{相关条件再次出现}
\rightarrow
d_s'
\]

所以：

\[
\boxed{
\text{drive reduction}
\sim
\text{部分性欲满足后的当前消减结构}
}
\]

但：

\[
\boxed{
\text{drive}
\neq
d_s
}
\]

并且：

\[
\boxed{
\text{驱力降低理论}
\neq
\text{三欲分类}
}
\]

---

# 七、自我决定理论

自我决定理论（Self-Determination Theory，SDT）是一套关于人类动机、人格发展与福祉的理论框架，其中把 autonomy、competence 和 relatedness 作为三种基本心理需要，并研究社会环境怎样支持或者阻碍这些需要及相关动机。

## 12. 自主、胜任与关系需要

### 文字解释

自我决定理论中的三个基本心理需要常被概括为：

**自主（autonomy）**

主要涉及行为具有自愿性和自我认同感。

**胜任（competence）**

涉及主体感受到自己能够有效行动、掌握任务和产生作用。

**关系性（relatedness）**

涉及与他人连接、关心以及被关心的体验。

由于刚好也是三个类别，很容易产生一种直觉：

> 自主、胜任、关系性是不是正好分别对应三欲？

这种对应不能成立。

但双方在现实内容上当然可能交叉。

例如，一个与“胜任”有关的现实过程，在三欲模型中可能包含：

> 我必须达到某个标准

这样的情欲。

也可能同时包含：

> 身体需要维持工作能力

这样的性欲。

关系性需要所涉及的亲近与连接，也可能出现在：

- 性欲；
- 情欲；
- 爱欲；

共同参与的关系行为中。

因此：

> SDT 描述的需要内容

可以成为三欲分析的现实对象。

但它们不是三欲分类本身。

### 符号与结构对照

自我决定理论中的三个基本心理需要可以表示为集合：

\[
\{
\text{autonomy},
\text{competence},
\text{relatedness}
\}
\]

三欲模型的具体欲望分类为：

\[
d_i\in\{d_s,d_c,d_l\}
\]

两者都具有“三项”形式，但：

\[
\boxed{
\{
\text{autonomy},
\text{competence},
\text{relatedness}
\}
\neq
\{d_s,d_c,d_l\}
}
\]

---

## 13. 三种心理需要为什么不是三欲

### 文字解释

两套分类最根本的不同在于：

> **分类依据不同。**

三欲动力学模型并不首先问：

> 这个欲望追求的是自主、胜任、关系，还是其他内容？

而是问：

> **这个已经充分拆分的具体欲望，具有怎样的基本动力学特征？**

因此，一个指向 competence 的具体欲望仍然需要继续判断：

> 它满足以后是条件依赖性再生、增殖，还是与相关他利态绑定。

同样，一个与 relatedness 有关的动力，也不能因为它发生在人际关系中，就直接归入爱欲。

例如：

> “我必须让别人接受我”

明显涉及关系。

但在三欲模型中，它可能首先需要作为掌控内容进入情欲分析。

另一方面，一个具体爱欲虽然与关系有关，也不是因为：

> “人有 relatedness need”

就被定义成爱欲。

爱欲的分类依据仍然是：

> **与相关他利态绑定并同步。**

所以 SDT 与三欲模型可以讨论相同的现实生活领域，但它们在不同理论维度上切分问题。

### 符号与结构对照

三欲分类依据：

\[
d_i
\xrightarrow{\text{基本动力学特征}}
\{d_s,d_c,d_l\}
\]

而不是：

\[
d_i
\xrightarrow{\text{欲望内容}}
\{d_s,d_c,d_l\}
\]

因此：

\[
\boxed{
\text{relatedness}
\neq
d_l
}
\]

\[
\boxed{
\text{competence}
\neq
d_c
}
\]

\[
\boxed{
\text{autonomy}
\neq
\text{某一种固定三欲}
}
\]

---

# 八、依恋理论

依恋理论关注依恋关系和依恋行为系统，尤其讨论人在威胁、痛苦或需要支持时怎样寻求依恋对象的接近和保护，以及早期关系经验怎样参与形成关于自己和他人的内部工作模型。安全基地和安全港是依恋理论中的核心结构之一。

## 14. 依恋关系与内部关系结构

### 文字解释

依恋理论与三欲模型中的爱欲和他利态存在几个容易让人联想到彼此的地方。

第一：

两者都承认：

> **关系经验可以进入主体后续内部结构。**

依恋理论中的内部工作模型描述过去依恋经验怎样参与主体对于自己、他人以及未来关系的预期。

三欲动力学模型则允许：

> 关系表征、主体侧他利状态结构

进入主体状态：

\[
\Sigma_S
\]

并参与之后欲望形成。

第二：

两者都关注：

> 关系不是一次行为，而是跨时间持续存在的结构。

第三：

两者都可能解释：

> 为什么同一个关系对象能够持续影响主体之后的行为和状态。

但这些相似仍然不足以证明：

> 依恋 = 他利态，

或者：

> 依恋动力 = 爱欲。

依恋理论中的依恋行为系统具有自己的功能结构，例如在威胁和痛苦时寻求依恋对象的接近、安全港与安全基地。

三欲模型中的他利态则定义为：

> **对称非自利关系。**

两者正在切分的关系维度明显不同。

### 符号与结构对照

依恋理论可以粗略示意为：

\[
\text{长期关系经验}
\rightarrow
\text{内部工作模型}
\rightarrow
\text{后续依恋相关认知、情绪与行为}
\]

三欲模型：

\[
\text{主体侧相关他利状态结构}
\subset
\Sigma_S
\]

并参与：

\[
\Sigma_S
\rightarrow
d_{l,S}^{O}
\]

两者都允许：

\[
\text{过去关系经验}
\rightarrow
\text{之后内部结构}
\]

但：

\[
\boxed{
\text{内部工作模型}
\neq
\text{主体侧他利状态结构}
}
\]

---

## 15. 依恋、他利态与爱欲的区别

### 文字解释

这里最需要防止两个直接映射：

> **安全型依恋 = 爱**

以及：

> **依恋动力 = 爱欲。**

这两个等式都不能建立。

依恋理论中的 attachment 主要围绕：

- 依恋行为系统；
- 接近依恋对象；
- 获得保护与安全；
- 安全基地；
- 内部工作模型；

展开。

三欲模型中的他利态则按照：

> **对称非自利关系**

定义。

爱欲进一步定义为：

> **与相关他利态绑定并同步、以对象效用改善为动力指向，并解释这一他利关系为何能够在主体内部持续形成相应动力的当前欲望。**

因此，一个关系完全可能具有明显依恋结构，却仍需要另外判断：

> 是否符合三欲模型中的他利态条件。

同样，一个主体对另一个主体存在明显接近、安全或依赖动力，也不能因此直接证明：

> 其动力指向是对象效用改善。

依恋和爱欲可以在现实中共同存在。

但它们不是同一层级的概念。

### 符号与结构对照

不能建立：

\[
\text{attachment} =
\text{他利态}
\]

也不能建立：

\[
\text{secure attachment} =
\text{爱}
\]

或者：

\[
\text{attachment motivation} =
d_l
\]

因此：

\[
\boxed{
\text{依恋关系结构}
\neq
\text{他利态}
}
\]

以及：

\[
\boxed{
\text{依恋动力}
\neq
\text{爱欲}
}
\]

是否存在爱欲仍然需要分析：

\[
\text{相关他利态}
\]

与：

\[
d_{l,S}^{O}
\]

之间的结构。

# 九、总体对照

## 16. 可以比较什么，不能互换什么

### 文字解释

经过前面的比较，可以看到：

> 三欲动力学模型与许多已有理论并不是完全没有共同结构。

相反，很多局部结构都可以找到明显相似。

身体调节可以与稳态、异稳态和驱力降低进行比较。

情欲在人类中的掌控表现可以与知觉控制理论中的参考—知觉调节结构进行比较。

基础状态—行为—环境循环可以与强化学习进行比较。

欲望与满足的区分可以与 “wanting / liking” 的分离进行比较。

人类具体动力内容可以与自我决定理论中的心理需要交叉。

爱欲与他利态则可以和依恋理论中的长期关系表征进行局部比较。

但是：

> **所有这些相似都只发生在某一个局部分析维度。**

三欲模型没有把任何一个外部理论整体重新命名为性欲、情欲或爱欲。

### 符号与结构对照

| 外部理论或概念 | 可以比较的三欲结构 | 不能直接互换 |

| 稳态 | 身体条件、调节、满足后的恢复 | 稳态 ≠ 性欲 |
| 异稳态 | 预期性身体调节、状态中的预期 | 异稳态 ≠ 性欲 |
| 知觉控制理论 | 参考、当前知觉、现实调节 | control ≠ 情欲 |
| 强化学习 | 状态、行动、环境结果、后续状态 | reward ≠ 满足；reinforcement ≠ 三欲强化 |
| 激励显著性 | 动力与享乐结果可以分离 | “wanting” ≠ 三欲中的一般欲望 |
| 激励敏化 | 后续奖励动力可能增强 | sensitization ≠ 情欲增殖 |
| 驱力降低理论 | 身体需要形成动力、满足后下降 | drive ≠ 性欲 |
| 自我决定理论 | 现实中的动力内容存在交叉 | 三种心理需要 ≠ 三欲 |
| 依恋理论 | 长期关系经验进入内部结构 | attachment ≠ 他利态 / 爱欲 |

\boxed{

\neq

}
\]

\[
\boxed{
\text{性欲}
\neq
\text{drive}
}
\]

\[
\boxed{
\text{情欲}
\neq
\text{控制论中的 control}
}
\]

\[
\boxed{
\text{掌控满足}
\neq

}
\]

\[
\boxed{
\text{三欲强化}
\neq
\text{reinforcement learning}
}
\]

\[
\boxed{
\text{情欲增殖}
\neq
\text{incentive sensitization}
}
\]

\[
\boxed{
d_i
\neq
\text{incentive salience “wanting”}
}
\]

\[
\boxed{
\text{SDT 三种基本心理需要}
\neq
\text{三欲}
}
\]

\[
\boxed{
\text{attachment}
\neq
\text{他利态}
}
\]

\[
\boxed{
\text{attachment motivation}
\neq
\text{爱欲}
}

## 17. 三欲模型自身的分类位置

### 文字解释

把这些相关理论放在一起以后，可以更清楚地看到三欲动力学模型自身真正的分类位置。

三欲模型首先建立的是一个主体动力过程：

> 状态形成欲望。

> 状态与欲望共同参与行为。

> 行为进入真实世界。

> 行为与其他现实过程共同产生实际变化。

> 主体在当前状态参与下形成实际感受结构。

> 实际感受结构和其他状态演化继续更新主体状态。

在这个基础过程上，三欲模型进一步选取：

> **具体欲望**

作为分类对象。

因此，它没有直接按照：

- 生理调节变量；
- 环境奖励；
- 行为方式；
- 知觉误差；
- 心理需要内容；
- 关系类型；

进行三欲分类。

真正的分类问题是：

> **在当前分析问题下，一个已经经过必要拆分、达到最粗充分尺度的单一动力成分，具有什么基本动力学特征？**

如果满足以后：

> 当前欲望消减，并主要在相关条件再次出现以后重新形成，

则进入性欲分类。

如果：

> 当前满足本身对之后相关欲望具有增殖作用，

则进入情欲分类。

如果：

> 当前动力与相关他利态绑定并同步，

则进入爱欲分类。

因此，其他理论可以帮助说明：

> 为什么某些三欲结构会让人产生熟悉感。

但三欲模型最终仍然需要按照自身的：

> **分类对象**

和：

> **分类标准**

独立判断。

### 符号与结构对照

三欲模型的基础过程为：

\[
\Sigma_t\rightarrow\mathcal D_t
\]

\[
(\Sigma_t,\mathcal D_t)\rightarrow A_t
\]

\[
A_t+\text{其他现实过程}
\rightarrow
\text{实际变化}
\]

\[
(\Sigma_t,\text{实际变化})
\rightarrow
\text{实际感受结构}
\]

\[
(\Sigma_t,\text{期间其他状态演化},\text{实际感受结构})
\rightarrow
\Sigma_{t+1}
\]

三欲的分类对象为：

\[
\boxed{
d_i
}
\]

即：

> 当前分析问题下已经达到最粗充分尺度的具体欲望。

分类前提为：

\[
\boxed{
\text{一个具体欲望只能属于一种三欲类型}
}
\]

分类依据为：

\[
\boxed{
\text{具体欲望的基本动力学特征}
}
\]

三种基本动力学特征分别为：

\[
\boxed{
\text{性欲：满足后的条件依赖性再生}
}
\]

\[
\boxed{
\text{情欲：增殖}
}
\]

\[
\boxed{
\text{爱欲：与相关他利态绑定并同步}
}
\]

因此：

\[
\boxed{
\text{对象、目标、行为、结果或外部理论中的相似概念}
\not\Rightarrow
\text{三欲类型}
}
\]

最终仍然需要回到：

\[
\boxed{
d_i
\xrightarrow{\text{基本动力学特征}}
\{d_s,d_c,d_l\}
}
\]

进行分类。

---

# 结语

三欲动力学模型与稳态、异稳态、知觉控制理论、强化学习、激励显著性、驱力降低理论、自我决定理论和依恋理论之间，都可以找到局部可比较结构。

这些比较主要能够帮助澄清：

- 身体调节与性欲不是同一个层级；
- 控制系统与情欲不是同一个概念；
- reward、满足、反馈和实际感受结构不能互换；
- 强化学习中的 reinforcement 与三欲模型中的强化不同；
- 激励显著性中的 “wanting” 不是三欲模型中所有欲望的通称；
- 激励敏化不能直接等同于情欲增殖；
- 心理需要内容不能直接映射为三欲类型；
- 依恋关系不能直接等同于他利态或爱欲。

因此，相关理论的主要作用不是：

> **为三欲找到另一套已经存在的名称。**

而是：

> **通过比较明确三欲模型正在什么层级上分析问题，又在哪些相似结构之后仍然坚持不同的概念边界。**

三欲模型自身最核心的分类位置仍然是：

> **先把现实动力拆分到具体欲望尺度，再按照其基本动力学特征区分性欲、情欲和爱欲。**
